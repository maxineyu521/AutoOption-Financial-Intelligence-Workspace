Current Version Strengths

  • Final-answer truth pass is now 0.90, which is in a strong range for this benchmark.
  • The Analyst now reliably answers the requested slots or explicitly discloses when a slot is not answerable.

Current Version Limitations

  • Critic and Finalizer still compress non-actionable answers meaningfully; the safety layer is working, but it still trims too much information.
  • Downgraded answers still sit near the minimum usefulness floor rather than preserving a stronger user-facing read.

Audience-ready Summary

  • Across these 4 iterations, final truth pass improved from 0.55 in the first run to 0.90 in the latest run.
  • The strongest truth-pass run is `Protected Watchlist Floor + Re-eval`, while the strongest final informational completeness run is `Protected Watchlist Floor + Re-eval`.
  • Compliance failure rate improved from 0.25 to 0.05; the cleanest compliance profile is `Protected Watchlist Floor + Re-eval`.
  • The latest run still shows non-actionable information compression through Critic's centered delta (`-0.050`), so safety is strong but not free.
  • The current best read is that the workflow is now strong at evidence grounding and hard safety, but still only average on downgraded-answer usefulness floor (`0.600`).
Read the Critic headline metric as a centered delta, not a success rate: values near 0 mean little compression, more negative values mean stronger flattening, and positive values mean downstream clarification.
